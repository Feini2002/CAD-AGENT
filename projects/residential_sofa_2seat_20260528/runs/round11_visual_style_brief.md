# round11 visual style brief

## 参考
- 截图：左参考块 `5S03232`（handle 4A2）+ 用户标注（全封闭/无靠垫/座应凸出）
- 任务：**同款式两座**；视觉同款；**不**逐线 clone 343 段碎线

## 部件（常识）
- [x] 左扶手 — 独立圆角矩形条，**前缘不封死**座区
- [x] 右扶手 — 同上
- [x] 座垫 ×2 — **闭合**轮廓；前缘 **凸出** 扶手前缘约 **30mm**（取整）
- [x] 靠垫 ×2 — **略椭圆**或圆角矩形 + 1 条缝线（不是框内细横线）
- [x] 靠背顶栏 — 与靠垫分离可读的后顶缘

## 造型语言
- assembly: **open**（禁止整圈 `_outer_shell` 全封闭 tub）
- seat_vs_arm: protrude_forward_mm ≈ **30**
- forbidden: 全封闭外框 / schematic 等分盒 / 断线碎拼 / 框内假靠垫

## 尺寸（取整，视觉优先）
- reference_width_mm: 2800（三座）
- target_width_mm: **1870**（2800×2/3≈1867 → **取整 10mm**，不纠结 1866.7）
- gap_from_reference_mm: **400**
- height_mm: **960**（与参考同高即可，不必微调）

## 弧度（差不多即可）
- corner_r_mm: **≈30**（25～35 均可，不必死扣 probe）
- seat_front: 浅弧 **或** 圆角即可，与参考 **看起来同级**

## 画法
- 每部件 **一条闭合轮廓**（少断线）
- 数字 audit 为辅助；**visual 不过不交付**
