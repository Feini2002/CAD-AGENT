# Sample Blank Shell Expected Notes

本文件记录空壳布局 pipeline 的非 CAD 预期，不作为真实 CAD 几何验收。

- 输入应来自人工 `SHELL_MODEL` 或等价结构化空壳模型。
- pipeline 应输出 shell、project、circulation candidates、function zones、placements、layout proposal、design proposal、CAD_PLAN、dry-run report 和 unverified verification report。
- benchmark 至少覆盖 retail、office、residential、restaurant 四个不同 workflow。
- 没有真实 CAD 落图和实体回读前，verification status 必须保持 `unverified`，不得声称几何准确。
