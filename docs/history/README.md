# History

本目录存放已完成计划、旧快照和长历史。这里的内容用于追溯原因，不作为默认上下文入口。

## 当前入口

| 需要 | 入口 |
| --- | --- |
| 唯一主计划 | `../../CORE_RESTRUCTURE_PLAN.md` |
| 短上下文 | `../../CORE_CONTEXT_BRIEF.md` |
| 当前状态 | `../status/current.md` |
| 当前交接 | `../handoffs/current.md` |

## 归档分区

| 目录 | 内容 |
| --- | --- |
| `snapshots/` | 根目录或关键文档的历史快照 |
| `completed-plans/` | 已完成或已失活的执行计划 |
| `changelog/` | 从当前 changelog 压出的长历史 |

历史文档可以保留旧数字和旧路径，但必须被视为历史快照；当前表 C 以 coverage JSON 为准。
