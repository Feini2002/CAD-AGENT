# CAD Agent 开发路线图

## 阶段 1：通用开发包工作区

目标：

建立可持续、可迁移的 CAD Agent 文件结构、规则、记录方式。

完成标准：

- 有入口 README。
- 有状态记录。
- 有变更记录。
- 有问题记录。
- 有长期规则。
- 有第一版目录框架。

## 阶段 2：CAD_PLAN 最小闭环

目标：

让一句简单白话可以被转换成一个可校验的 CAD_PLAN。

完成标准：

- 有 `cad_plan.schema.json`。
- 有 `draw_test_cabinet.json`。
- `validate_plan.py` 可以检查测试计划。

## 阶段 3：dry-run 预演

目标：

执行前先输出将要绘制的对象，不直接进入 CAD。

完成标准：

- `dry_run_plan.py` 可以读取 CAD_PLAN。
- 能输出对象类型、尺寸、图层、预估外包框。

## 阶段 4：预览绘制

目标：

把通过校验的 CAD_PLAN 画到 `CODEX_PREVIEW` 图层。

完成标准：

- 可以画一个测试柜。
- 可以加文字。
- 可以加基本尺寸。
- 不默认保存正式 DWG。

## 阶段 5：回读验证

目标：

画完后能检查实体数量、图层、尺寸、范围。

完成标准：

- 能报告新增实体数量。
- 能报告关键尺寸。
- 能说明对象在哪个图层。

## 阶段 6：对象库

目标：

让柜子、床、桌、货架、收银台等对象有默认画法。

完成标准：

- 有 `libraries/objects/` 对象定义。
- 每个对象有默认尺寸、图层、绘制方式。

## 阶段 7：行业包

目标：

支持住宅、零售、办公、餐饮、展厅、酒店、教育、医疗、工业等不同空间类型，并保留 `custom` 自定义场景。

完成标准：

- 有 `libraries/domains/residential.json`。
- 有 `libraries/domains/retail.json`。
- 用户白话可以映射到对应行业对象。

## 阶段 8：跨电脑迁移检查

目标：

让本文件夹复制到新电脑后，可以快速判断是否具备同等执行能力。

完成标准：

- 能说明本文件夹、运行环境、项目图纸三者的区别。
- 能在新电脑运行 `validate_plan.py`。
- 能在新电脑运行 `dry_run_plan.py`。
- 能确认 CAD-MCP 或 CAD COM 是否可用。
- 能用同一个 CAD_PLAN 在新电脑进入预览绘制流程。
