# CAD Agent 工作流

本工作流是通用流程，不绑定当前家装图纸。进入任何具体项目时，先读取该项目的上下文，再生成 CAD_PLAN。

## 标准流程

```text
1. 读取用户白话
2. 判断任务类型
3. 读取项目上下文
4. 生成 CAD_PLAN
5. 校验 CAD_PLAN
6. dry-run 预演
7. 绘制到 CODEX_PREVIEW
8. 回读验证
9. 等待用户确认
10. 用户确认后再正式落图或保存
```

## 卡壳分支

如果预览绘制失败、画不准、缺少截图或无法验证，不继续盲目重试。先进入：

```text
CAD_AGENT_BLOCKER_PLAYBOOK.md
-> scripts/self_check.py
-> scripts/render_preview.py --check
-> 最小复现
-> 最小修复
-> 重新验证并记录
```

## 什么情况下要问用户

- 没有明确位置。
- 没有明确尺寸，且对象库没有默认值。
- 用户要求修改正式图层。
- 用户要求覆盖或保存 DWG。
- 计划的置信度低于 0.8。

## 什么情况下可以直接预览

- 用户明确说“测试一下”。
- 只画到 `CODEX_PREVIEW`。
- 不覆盖、不保存、不删除已有正式内容。
- 对象尺寸和位置足够明确。

## 每次执行后的回复

回复要包含：

- 我画了什么。
- 画在哪个图层。
- 使用了哪些关键尺寸。
- 哪些内容是预览。
- 下一步用户可以怎么确认或修改。
