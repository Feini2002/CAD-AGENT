# exhibition Agent

Lightweight scene agent for exhibition and display CAD work.

This scaffold records only exhibition-specific vocabulary and preferences. Reuse core for common design, layout, CAD execution, and verification.

## Scope

- Booth, display wall, display path, exhibit object, storage, and visitor flow vocabulary.
- Exhibition-specific layout preferences.

## Core Reuse Contract

- Use core for drawing analysis, project models, layout, CAD_PLAN generation, execution, safety, and verification.
- Do not copy core logic into this agent.
