# exhibition Rules

## Scene Differences

- Keep visitor flow readable.
- Prefer clear display sequences when entrances and exits are known.
- Treat display walls, feature exhibits, and booth fronts as priority elevation targets.
- Keep storage or staff-only zones separate when the brief provides them.

## Defaults

- Display wall priority: high.
- Preview layer: `CODEX_PREVIEW`.

## Core Boundary

- Do not implement visitor-flow algorithms here.
- Do not implement object generation here.
- Do not implement CAD execution or verification here.
- Add only exhibition-specific preferences when needed.
