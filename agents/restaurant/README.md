# restaurant Agent

Lightweight scene agent for restaurant CAD work.

This scaffold records only restaurant-specific vocabulary and preferences. Reuse core for common design, layout, CAD execution, and verification.

## Scope

- Dining, service, kitchen, cashier, queue, and circulation vocabulary.
- Restaurant-specific layout preferences.

## Core Reuse Contract

- Use core for drawing analysis, project models, layout, CAD_PLAN generation, execution, safety, and verification.
- Do not copy core logic into this agent.
