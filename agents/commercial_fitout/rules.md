# commercial_fitout Rules

## Scene Differences

- Prefer entrance-facing display zones when the plan has a clear storefront or entry.
- Place cashier areas near exit or entrance control points, while preserving circulation.
- Group shelves, display cabinets, and feature fixtures instead of scattering isolated objects.
- Treat display walls, cashier back walls, and storefront elevations as priority elevation targets.
- Keep main circulation wider than secondary circulation by default.

## Defaults

- Main aisle preference: 1200 mm.
- Secondary aisle preference: 900 mm.
- Preview layer: `CODEX_PREVIEW`.

## Core Boundary

- Do not implement drawing analysis here.
- Do not implement collision checks here.
- Do not implement CAD_PLAN validation, dry-run, execution, screenshot, or entity readback here.
- Store only scene preferences and workflow intent.
