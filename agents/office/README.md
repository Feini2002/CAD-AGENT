# office Agent

Lightweight scene agent for office CAD work.

This scaffold is intentionally small. Add office-specific rules only after real office workflows appear. Reuse core for all common CAD and design capabilities.

## Scope

- Office planning preferences.
- Workstation, meeting, reception, circulation, and storage vocabulary.

## Core Reuse Contract

- Use core for drawing analysis, project models, layout, CAD_PLAN generation, execution, safety, and verification.
- Do not copy core logic into this agent.
