# custom Rules

## Scene Differences

- Use this agent for temporary or project-specific preferences only.
- Keep assumptions local to the project brief or project model.
- Promote a rule to a named scene agent only after repeated use.
- Promote a rule to core only if two or more scenes need it.

## Defaults

- Preview layer: `CODEX_PREVIEW`.

## Core Boundary

- Do not implement generic capabilities here.
- Do not create permanent global rules from one project.
- Do not implement CAD execution or verification here.
