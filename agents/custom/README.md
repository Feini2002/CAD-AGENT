# custom Agent

Lightweight scene agent for project-specific or uncategorized CAD work.

Use this only when a request does not fit a named scene agent yet. Promote repeated custom rules into a named agent or core only after there is evidence they repeat.

## Scope

- Temporary scene preferences.
- Project-specific vocabulary that should not become global yet.

## Core Reuse Contract

- Use core for drawing analysis, project models, layout, CAD_PLAN generation, execution, safety, and verification.
- Do not copy core logic into this agent.
- Do not let one project's assumptions become global defaults.
