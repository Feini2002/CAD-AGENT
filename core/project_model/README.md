# core/project_model

职责：把图纸实体、用户白话、项目类型、场景规则和已知限制合并成统一 `PROJECT_MODEL`。

目标内容：

- 单位、比例、图层约定。
- 项目类型。
- 空间列表和空间边界。
- 入口、墙体、门窗、柱子。
- 可布置区域和不可用区域。
- 已有对象、用户需求、系统推断、待确认问题。

当前状态：scaffold。职责已明确，schema 与实现尚未开始。

边界：

- 项目模型是 Core 的通用上下文。
- 真实项目资料应进入 `projects/`，不写死在 Core。
- 场景 Agent 只能补默认参数和场景偏好，不能替代项目模型。
