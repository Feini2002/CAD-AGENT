# core/layout_engine

职责：在空间边界、入口、约束和对象集合内生成通用布局候选，输出 `LAYOUT_PROPOSAL`。

通用能力：

- 边界内布置。
- 碰撞检查。
- 通道宽度检查。
- 对齐墙体。
- 主入口和主视觉关系。
- 对象组合和候选方案评分。

当前状态：prototype。当前代码只包含最小 bbox、碰撞和单对象边界内布置原型，尚未覆盖完整通道、对齐墙体、多候选评分。

边界：

- 本模块先做通用布局，不绑定工装。
- “服装店入口展示优先”“卧室床头靠实墙”等规则应由轻量场景 Agent 作为偏好输入。
- 本模块不直接调用 CAD；落图交给计划和执行层。
