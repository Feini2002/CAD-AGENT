# Negative Examples

- 错误：用户说“试一下”，路由成 formal acceptance。原因：quick trial 不能静默升级成训练。
- 错误：用户说“沉淀资产”，只派普通绘图 Agent。原因：资产沉淀必须先过资产守门与复用审计。
- 错误：把未登记 Agent 放进 `requiredAgents`。原因：未登记 Agent 不能本轮生效。
- 错误：分发建议里写“任务已完成”。原因：编排只产生路线和 gate，不产生完成证据。
- 错误：删除任务未要求 delete scope gate。原因：删除范围和 victim preview 是 hard gate。
