# core/proposal_engine

职责：在落图前生成可解释的方案说明，输出 `DESIGN_PROPOSAL`。

方案应说明：

- 准备做什么。
- 为什么这样做。
- 哪些来自图纸。
- 哪些来自用户。
- 哪些是系统推断。
- 哪些需要确认。
- 用户通过后会生成哪些 CAD_PLAN。

当前状态：prototype。当前代码只包含最小 `DESIGN_PROPOSAL` 构建和确认后转 `CAD_PLAN` 原型，尚未覆盖完整多方案比较。

边界：

- 本模块不直接画图。
- 本模块是用户确认门，避免从白话直接跳到 CAD。
- 场景 Agent 可提供业务偏好，但方案结构仍由 Core 统一。
